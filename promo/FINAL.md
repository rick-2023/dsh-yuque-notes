## 一、小红书（种草风 · 配图无外链）

### 标题
和 DeepSeek 聊天时，灵感再也不用复制粘贴了😭

### 正文
不是，谁懂啊！！

跟 DeepSeek 聊着聊着突然冒出一句好东西，
结果还要：选中 → 复制 → 打开语雀 → 新建小记 → 粘贴 → 发送……

我直接人麻了。

于是做了这个开源插件：
dsh-yuque-notes 🐣

现在只要：
1️⃣ 在对话里划一段文字
2️⃣ 右下角点「记录到小记」
3️⃣ 自动进语雀小记！！

真的有被爽到。

更香的是：
✨ 输入框旁边也能直接写小记
✨ ⌘/Ctrl + Enter 秒发送
✨ 不用申请语雀 Token
✨ 用已经登录的浏览器自动发
✨ MIT 开源，自己也能改

适合谁：
🧠 边用 AI 边攒灵感的人
📚 想把对话沉淀进语雀的人
🧘‍♀️ 不想折腾 API / Token 的人

我自己现在已经上瘾了——
聊到哪记到哪，灵感不再蒸发💧
